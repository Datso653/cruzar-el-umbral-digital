## Sobre los datos

Los resultados provienen del relevamiento a campo de 998 comercios del AMBA (octubre de 2025) y de su seguimiento mensual (noviembre 2025 – mayo 2026), realizado en el marco del concurso de datos del MIT LIFT Lab. Este repositorio **no contiene datos crudos**: el mapa muestra solo celdas de ~1,5 km con 3 o más comercios, de modo que ningún comercio queda identificado.
